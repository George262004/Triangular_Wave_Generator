# Triangular Wave Generator using LM741

This repository contains the **schematics and PCB layout** for a triangular wave generator circuit designed using the **LM741 op-amp** in **Altium Designer**.

## 🛠 Project Overview

- **IC Used**: LM741
- **Output Frequency**: ~1 kHz
- **Design Software**: Altium Designer
- **Contents**: Schematics and PCB layout files
- **Status**: ✅ Tested and working

This circuit is a basic implementation of a triangular wave generator and is intended for educational or experimental use. It does **not** include advanced features like variable frequency or amplitude control.

## 📁 Files Included

- Altium project files (`.SchDoc`, `.PcbDoc`, etc.)
- Board and schematic designs ready for fabrication
